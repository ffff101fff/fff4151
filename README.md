# DATA KOREA

대한펜싱협회 공개 경기결과로 만든 펜싱 기록 서비스입니다.
선수 이름 하나로 전적을 찾고, 대회 배정표를 붙이면 다음 상대를 바로 분석합니다.

- 사이트: https://fff4151.netlify.app
- 데이터: 대한펜싱협회 경기결과 2020~2026 (대회 124개 · 종별 2,359개 · 경기 306,570건 · 선수 약 9,000명, 기준일 2026-11-16)

## 주요 기능

| 화면 | 내용 |
|---|---|
| 선수 찾기 | 선수·소속 검색, 대회별 성적, 상대 전적, 전국·팀 안 순위 |
| 상대 분석 | 배정표의 상대 이름을 붙여 넣으면 상대별 전적과 레이팅을 한 번에 비교 |
| 랭킹 | 초·중·고·대학·일반부와 동호인 Elo 랭킹 (종목·성별별) |
| 대회 | 예정 대회 일정, 지난 대회 결과, 학교·클럽 실적 |
| 내 실적 | 내 선수 등록, 시즌 요약, 진학용 실적표 |

- 처음 온 사용자를 위한 3단계 미션: 내 선수 찾기 → 다음 상대 분석 → 팀원에게 공유
- 화면 아래 '의견 보내기'로 1분 설문

## 파일

- `index.html`: 앱 전체 (HTML·CSS·JavaScript 한 파일)
- `data.json`: 경기 기록 데이터

정적 파일이라 폴더를 그대로 웹 서버나 Netlify에 올리면 실행됩니다.

## 데이터와 개인정보

- 대한펜싱협회 홈페이지에 공개된 경기결과만 사용합니다.
- 생년월일, 사진, 연락처는 저장하지 않습니다.
- 방문 기록은 기기마다 임의로 만든 익명 번호로만 남깁니다.
- 2027년 대회 일정은 협회 「2027년도 사업계획(안)」 기준이며 바뀔 수 있습니다.
